# Keep private capture upstream of the public Portfolio

Daily Capture and original Media Items belong to a private capture service, with LifePilot as the eventual iPhone/iPad client and the Mac as the bulk-intake host. The public Portfolio consumes only approval-backed Public Media Selections. This preserves one human publication gate, avoids turning the public repository into a photo library, and lets iOS and macOS share the same date-scoped capture contract without coupling private input to GitHub Pages.
