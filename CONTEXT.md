# Daily Capture And Public Portfolio

This context connects private daily capture and media review to the public Portfolio without making private source material public by default.

## Language

**Daily Capture**:
A private, date-scoped record containing a rough text or voice note and zero or more imported photos.
_Avoid_: Public post, Daily Log article

**Media Item**:
A deduplicated private photo record with source provenance and a captured-date confidence level.
_Avoid_: Portfolio image, attachment

**Media Suggestion**:
A ranked relationship between a Media Item and a Daily Capture or Daily Log date. It is not permission to publish.
_Avoid_: Selected photo, automatic publication

**Publication Decision**:
The human choice to publish one Media Item, publish no photo, or leave the date pending.
_Avoid_: Suggestion, approval inference

**Public Media Selection**:
The Level 0 projection produced from a Publication Decision for consumption by the public Portfolio.
_Avoid_: Original photo, private media record

**Capture Surface**:
The mobile-first interface used for rough daily notes and photo selection, eventually owned by LifePilot.
_Avoid_: Portfolio admin

**Review Surface**:
The interface used to compare suggestions and make Publication Decisions. It may be used from iPhone or Mac.
_Avoid_: Gallery

**Bulk Intake**:
Mac-oriented ingestion of a folder or export containing many photos into the same Media Item catalog.
_Avoid_: Publication, review
